# Outputs: one standard per kind

One page per kind of thing that gets made for this business: an email, a
report, a page, an app, a dashboard. Each one says what it reads first (how
the business sounds, what it looks like), what it must never do, and how it
is checked. Add a kind when you need one. Nothing made here may look or sound
like a machine made it, or like it came off the shelf.

`vision.md`, at the top of this repo, says which of these get made and how
often. The look is picked once from three samples and lives in `brand.md`.
Every kind reads it, so change it there, never in one output.
