# What this business looks like

Not written yet. The first time a page, a report or a dashboard is made
here, you see three looks on one page, drawn from the Context Core
(`python3 scripts/oac-vision.py looks`). You say a number. The one you pick
is written here (`python3 scripts/oac-vision.py pick N`). Until then,
anything made here is plain black on white.

skip the three looks. If the owner set this business up with `/sac deploy` and
chose to start from their own look, this file already carries it.

## Never

Nothing made for this business looks like it came off the shelf. It is made
for this business: its words, its colours, its name at the top. Never the
look every AI tool makes (what people call vibe-coded): the purple fade, the
same rounded cards, the same font on every page, a badge on everything, a
glow, dark panels with bright green text, code font for ordinary words. One
accent colour, not three. Space, not boxes.
